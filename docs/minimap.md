# 小地圖與大地圖

依據：2026-11-26 試玩改進建議的小地圖項目。全部程式即時繪製（Canvas 2D），沒有圖檔。

## 一、小地圖（野外 HUD 右上，選單按鈕下方）

- **外觀**：圓形，電腦 128 px、手機橫拿（高度 ≤ 460）96 px、更矮 78 px。外圈有一個「N」標記，指出正北在哪。
- **視角**：以主角為中心、**跟著鏡頭轉**（鏡頭前方永遠朝上，和任務箭頭同一個方向感），可見半徑 30 公尺。
- **畫的東西**：
  - 地形：各區底色、河流、道路與村子廣場、橋、房屋屋頂、北方山脊與隘口缺口、古代石環、月泉、星晶林、樹叢。
  - 主角：白色箭頭（朝向 = 主角面對的方向）；隊友：職業色圓點。
  - 怪物（即時）：紅點＝一般、橘點＝精英、紫點＝Boss；目前鎖定的目標多一圈白框。
  - 村長（金色 !）、商人、待招募夥伴（藍色 !）、寶箱（只畫還沒開的）、石環祭壇／月光石碑／星晶簇／月泉（任務輪到時變金色）、吊橋絞盤、風車、古老巨木、星光鎮城門。
  - **任務目標**：金色星星；超出範圍時變成貼在邊緣的金色指針，指向目標的方向。距離照舊顯示在任務箭頭旁（小地圖不重複）。
- **操作**：點一下（或按 M）開大地圖。
- **開關**：選單 ☰ →「小地圖 開／關」，設定會記住（`localStorage` 的 `starwish.minimap`）。
- **不顯示的時候**：星光鎮裡（城鎮是安全區，地方不大）、選單展開時、過場播放時、選單關閉小地圖時。
- **效能**：地形底圖只畫一次（離屏畫布，每公尺 6 px）；每幀只做旋轉貼圖與標記。更新率 30 fps（畫質「低（省電）」20 fps）；分頁在背景時不畫。繪製一次約 0.04 ms（256 px，桌面 GPU）。

## 二、大地圖（選單「地圖」分頁，M 鍵）

- 整張主線地圖，正北朝上，開著時遊戲暫停（和背包、技能樹同一組分頁）。
- 標出：你與隊友、任務目標（金星呼吸動畫）、所有怪物營地（紅圈＋等級，精英營地橘色）、四個區域首領（王／精）、寶箱、調查點、村長、商人、夥伴、風車、古樹、星光鎮城門，以及六個區域的名稱（你所在的區域名稱是金色）。
- 右側欄：目前所在區域、任務標題與文字、到目標的距離、圖例。
- 手機橫拿：側欄縮窄，地圖與側欄都在畫面內（844×390 測過）。
- 星光鎮裡按 M 不開地圖，會提示「星光鎮裡不需要地圖，路標都在眼前」。

## 三、程式位置

| 檔案 | 內容 |
|---|---|
| `src/ui/mapDraw.ts` | 底圖、標記、`drawMini`／`drawFull`；`MAP` 為涵蓋範圍（x −42～42、z −77～43）、`MINI_RADIUS` 為小地圖半徑 |
| `src/ui/MiniMap.tsx` | HUD 的小地圖元件（canvas、更新率、點擊開大地圖） |
| `src/ui/menu/MapTab.tsx` | 大地圖分頁（畫布縮放、側欄） |
| `src/game/store.ts` | `MenuTab` 加了 `'map'`；`minimap` 設定與 `setMinimap` |
| `src/systems/input.ts` | `KeyM` → 地圖分頁 |
| `src/hud.css` | `.minimap`、`.map-*` 樣式 |

要加新的標記：在 `mapDraw.ts` 的 `drawMarkers` 加一段；固定地標加進 `LANDMARKS`，區域名稱位置在 `REGION_LABELS`。地形有改（河、道路、山脊）會自動跟著畫（直接讀同一份資料）；只有「樹叢」是裝飾用的隨機點，不對應實際樹木。

## 四、測試

`tools/qa/minimap-qa.mjs`（截圖在 `docs/minimap-qa/minimap/`），33 項：

- 出現與尺寸、位置（選單按鈕下方、靠右對齊）、畫面有內容。
- 方向：朝北／南／西／東時河分別在上／下／右／左（離屏直接呼叫 `drawMini`，因為鏡頭 yaw 每幀由 CameraRig 覆寫）；真實小地圖也符合目前鏡頭；主角箭頭角度（面向東、鏡頭朝西 → 朝下等四種）。
- 任務：距離只在任務箭頭顯示、範圍內有金星、太遠有邊緣指針。
- 怪物紅點。
- 點擊與 M 鍵開關大地圖（暫停、Esc 關閉）；大地圖比例（84:120）、主角位置、側欄內容。
- 選單項目、小地圖開關並記住、城鎮裡不顯示且 M 只出提示。
- 手機橫拿 844×390：不與任務欄、技能列重疊，大地圖放得下。
- 繪製耗時、主控台沒有錯誤。

## 五、已知與還沒做

- `town-qa` 的「反覆進出沒有累積幾何體」偶爾差 1～6 個（超過容許的 4）——關掉小地圖照樣會出現，是原本就有的串流時間差，不是小地圖造成。
- **沒有戰爭迷霧**：整張地圖一開始就看得到。要做的話需要把「走過的格子」存進存檔。
- 大地圖還不能點一下就自動走過去、也不能縮放拖曳。
- 城鎮沒有地圖（城鎮小，路標都看得到）。如果之後城鎮擴大，可以把城鎮配置也畫成一張。
- 手機實機的幀率與觸控手感沒驗證（自動測試用桌面 GPU）。
- 小地圖半徑固定 30 公尺，沒有放大縮小。
