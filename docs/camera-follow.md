# 鏡頭跟隨（走路自動轉向）

- 走路時鏡頭會慢慢轉到「前進方向的背後」。鍵盤、點擊自動移動都一樣。
- 轉動速度有上限（約 1.1 弧度／秒）。按側邊鍵（A／D）會一直弧形轉；往鏡頭方向倒退走（S，方向差超過約 150°）不轉，避免畫面翻面。
- **自己轉視角就暫停**：右鍵拖曳、手機單指拖曳、Q／E 任一個轉過，這一趟路鏡頭就聽你的；停下來約 0.35 秒後再出發才恢復自動轉向。
- 對話、過場、進出城鏡頭運鏡時不轉。
- 選單（☰）有「鏡頭跟隨 開／關」，會記住（`starwish.camfollow`）。
- 程式：`src/scene/CameraRig.tsx`（`auto` 參考與 yawT 的更新）、`src/game/store.ts`（`camFollow`）、`src/ui/Hud.tsx`（開關）。測試：`tools/qa/camfollow-qa.mjs`（11 項）。
