# 技能特效系統（Skill VFX System）

沿用遊戲原本的技術：Vite、React 19、React Three Fiber、three 0.187。沒有新增套件，也沒有用付費特效素材，全部用程式和基本幾何圖形畫。

## 檔案

| 位置 | 內容 |
|---|---|
| `src/vfx/` | 只管畫面，不知道傷害、怪物或存檔。遊戲和測試頁共用 |
| `src/vfx/VfxWorld.ts` | 特效世界：持有所有物件池，提供刀光、魔法陣、衝擊波、光柱、拖尾、粒子、GLB 模型特效、投射物追蹤 |
| `src/vfx/particles.ts` | 粒子層：一次繪製呼叫畫完全部粒子 |
| `src/vfx/shaders.ts` | 自訂著色器：粒子、刀光、拖尾、魔法陣、衝擊波、光柱、光暈 |
| `src/vfx/cues.ts` | 特效片段：刀光、命中火花、集氣、出手閃光、魔法陣、爆炸、治療光柱、治療光點 |
| `src/vfx/timeline.ts` | 時間軸播放器（不知道事件要做什麼，由使用的一方處理） |
| `src/vfx/pool.ts` | 固定上限的物件池 |
| `src/vfx/quality.ts` | 高畫質 / 省電的預算 |
| `src/vfx/bus.ts` | 戰鬥模擬 → 畫面的特效請求佇列 |
| `src/skills/demoSkills.ts` | 四個示範技能的資料：時間軸、命中方式、投射物外觀、特效參數 |
| `src/skills/hitTest.ts` | 命中判定（扇形、圓形、投射物到達） |
| `src/game/combat/damageCalc.ts` | 傷害公式（從原本的 `damage()` 抽出來，遊戲與測試頁共用） |
| `src/game/combat/skillRunner.ts` | 遊戲裡播放技能時間軸 |
| `src/scene/SkillVfx.tsx` | 遊戲裡的特效層 |
| `skill-lab.html`、`src/lab/` | 技能特效測試頁 |

## 分工：動作、特效、命中、傷害

一個技能是一條時間軸，上面有五種事件：

| 事件 | 遊戲裡由誰處理 | 做什麼 |
|---|---|---|
| 動作 `anim` | `skillRunner.ts` | 設定單位的攻擊動作；名稱存在 `actionClip`，之後 GLB 有動畫片段時用來挑片段 |
| 特效 `vfx` | `vfxBus` → `SkillVfx.tsx` → `cues.ts` | 只有畫面 |
| 命中 `hit` | `actions.ts` | 近戰與治療的命中判定（`hitTest.ts`），接著算傷害（`damageCalc.ts`） |
| 發射 `launch` | `actions.ts` | 產生投射物；投射物飛到目標才判定命中（`sim.ts`） |
| 音效 `sfx` | `skillRunner.ts` | 主角附近才播 |

- 命中之後，對每個被打中的目標播一次「命中反應」時間軸（火花、爆炸、治療光點）。這條只有特效和音效。
- 施放者倒下或被暈眩時，還沒到的命中與發射會取消。
- 時間軸滿了（遊戲 96 條、測試頁 128 條）會把最舊那條剩下的事件立刻觸發完，命中與發射不會消失。
- 換地圖、重新開始時，時間軸與特效全部清掉。

## 四個示範技能

| 技能 | 遊戲裡用在 | 時間軸 |
|---|---|---|
| 戰士斬擊 | 戰士普通攻擊 | 0 揮劍 → 0.08 揮砍聲 → 0.10 刀光 → **0.17 命中**（目標還在前方 160° 扇形內才算） |
| 弓箭射擊 | 弓箭手普通攻擊；連射、穿透箭也套用拖尾與命中火花 | 0 拉弓＋集氣 → **0.12 放箭**（出手閃光、弓弦聲）→ 箭帶拖尾飛到目標才命中 |
| 法師火球 | 法師技能 1「火球」 | 0 施法＋腳下魔法陣 → 0.05 集氣 → **0.40 發射** → 火球（核心、光暈、拖尾、火星）飛到目標 → 爆炸，半徑內其他怪物受六成傷害 |
| 聖者治療 | 聖者技能 2「治癒之光」 | 0 施法＋集氣＋目標腳下魔法陣 → 0.30 光柱 → **0.45 回復** → 治療光點 |

和原本的差別：

- 戰士普攻原本出手當下就扣血，現在等刀光掃到（約 0.17 秒）才扣。
- 火球原本 0.1 秒就發射，現在先展開魔法陣、0.4 秒後才發射。
- 治癒之光原本立刻回血，現在光柱升起後 0.45 秒才回。
- 傷害公式、射程、冷卻、MP 都沒變。

## 參數

每個技能一份 `FxParams`（`demoSkills.ts`）：

| 參數 | 用途 |
|---|---|
| `color`、`color2` | 主色、副色（漸層、外圈、煙） |
| `size` | 整體大小倍率 |
| `duration` | 主要特效的秒數（刀光、魔法陣、光柱） |
| `offset` | 發射點：施放者本地座標（x 右、y 上、z 前） |
| `range` | 攻擊距離：刀光半徑、射程 |
| `radius` | 作用半徑：爆炸、治療範圍 |
| `cooldown` | 冷卻秒數 |

- 射程、冷卻、爆炸半徑的預設值讀 `classes.ts`，遊戲平衡只有一份來源。
- 測試頁的調整只影響測試頁；遊戲裡的射程與冷卻仍以 `classes.ts` 為準。

## 新增一個技能

1. 在 `demoSkills.ts` 加一筆：時間軸用 `cues.ts` 裡的特效片段名稱，命中方式選 `arc`、`single`、`splash` 或 `heal`。
2. 需要新的畫面：在 `cues.ts` 加一個片段，用 `VfxWorld` 的方法組合。
3. 接進遊戲：在 `actions.ts` 施放技能的地方呼叫 `playSkill(id, 施放者, 目標, { onHit, onLaunch })`。
4. 測試頁會自動列出（技能清單在 `DEMO_ORDER`、職業對應在 `SKILL_OF_CLASS`）。

## Meshy / Blender 模型

- 技能資料的 `projectile.model` 是模型插槽：`{ key, url, scale, clip? }`。
- 載入後用 `VfxWorld.registerModel(key, 場景, 動畫)` 登記。有登記就用模型，沒有（載入中或失敗）就用程序化外觀。
- 模型特效也有物件池（高畫質 32、省電 16）。每個複製品有自己的 AnimationMixer，`clip` 是 GLB 裡的動畫名稱。
- 示範：測試頁的弓箭射擊用武器包的箭（`shared-arrow.web.glb`）。遊戲裡的箭本來就由 `CombatLayer` 畫，特效系統只畫拖尾。
- 角色動作：時間軸的 `anim` 事件名稱（`attack`、`cast`）會寫進單位的 `actionClip` 並遞增 `actionSeq`。目前角色是程式驅動的揮擊動作；換成有動畫片段的 GLB 角色時，用這個名稱挑片段即可。
- 模型請照現有流程先壓縮（`tools/assets/build-web.ps1`），只載入 `.web.glb`。

## 效能

- **繪製呼叫**：所有粒子只用 2 次繪製呼叫（一般混合一層、加亮混合一層）。刀光、魔法陣這類物件只在使用中才畫。
- **物件池**：
  - 物件需要時才建立，最多到上限。
  - 滿了就回收最舊的那個，所以大量攻擊時舊特效只會提早消失，物件數量不會一直增加。
  - 粒子超過預算就不再產生。
- **預先編譯**：建立特效世界時，每種著色器都先編譯好，第一次放技能不會卡一下。
- **遠處省略**：遊戲裡離主角超過 34 公尺的特效不播。
- **明亮場景**：草地是明亮的粉彩色，加亮混合容易變成一片白。主要用一般混合加上白色核心表現發光，加亮混合只用在火花與閃光。沒有用全螢幕光暈後製，手機比較省。

| 預算 | 高畫質（桌機） | 省電（手機預設） |
|---|---|---|
| 粒子（一般 / 加亮） | 1600 / 1000 | 600 / 360 |
| 每次噴發的粒子數 | ×1 | ×0.5 |
| 拖尾點數 | 24 | 12 |
| 刀光 / 拖尾 / 魔法陣 / 衝擊波 / 光柱 / 火球 | 16 / 32 / 12 / 24 / 8 / 24 | 8 / 16 / 6 / 12 / 4 / 12 |

遊戲的「省電模式」設定會一起切換特效預算。

## 技能特效測試頁

- 開 dev server 後瀏覽 `http://localhost:5183/skill-lab.html`；網頁版在遊戲網址後加 `skill-lab.html`。
- **切換職業**：上方按鈕或 1～4 鍵。
- **施放**：下方按鈕或空白鍵。
- **播放選項**：自動連放、忽略冷卻、壓力測試（周圍 20 個位置同時施放）、清除特效。
- **時間軸面板**：動作、特效、命中、發射、音效五軌，施放時有播放頭。
- **參數**：主色、副色、大小、持續時間、射程、作用半徑、冷卻、發射點（左右、高度、前後），還可以調遠距木樁的距離。
- **範圍標示**：黃圈是射程，紅圈是作用半徑。
- **顯示**：高畫質 / 省電、白天草地 / 夜晚。
- **效能數字**：FPS、繪製次數、三角形數、各物件池的使用量、超出預算與池滿回收次數。
- **手機**：預設用省電模式。面板直放時在下方、橫放時在右側，可以收起。

## 待驗證

- **實體手機**：目前只用桌面 GPU 模擬手機尺寸。實機的 FPS 和發熱都還沒量。
- **手感**：戰士普攻、火球、治療都比原本晚生效（0.17～0.45 秒），要實際玩過再決定要不要調整時間。
- **美術**：刀光在明亮草地上偏淡，可以用測試頁調整顏色與大小後再定。
- **Meshy / Blender 模型**：模型插槽已經可以用，但目前只用武器包的箭驗證過，還沒有用帶動畫的特效模型測試。
