# 選單 UI 規範（手機優先）

第一步重做了背包，隊伍、技能樹、商店之後也照這份規範改。樣式在 `src/menu2.css`，元件在 `src/ui/menu/`。

## 版面與斷點

| 裝置 | 條件 | 選單外框 | 背包 |
|---|---|---|---|
| 手機橫拿（主要目標） | 高 ≤ 560 且橫向 | 全螢幕，標頭一行（分頁、頭像、金幣、關閉） | 左：角色（200px）；右：格子。點裝備從右側滑出詳情 |
| 手機直拿 | 寬 ≤ 600 且直向 | 全螢幕，標頭兩行（第二行是頭像） | 上：角色；下：格子。點裝備從下方滑出詳情 |
| 平板 | 其餘 | 寬 ≤ 760 時全螢幕，否則置中面板 | 角色＋格子兩欄，詳情用彈出面板 |
| 電腦 | 寬 ≥ 1100 且高 > 560 | 置中大面板（最大 1180×760） | 角色｜背包｜詳情 三欄 |

- 高度用 `100dvh`（不支援時退回 `100vh`），四邊用 `env(safe-area-inset-*)` 避開瀏海與圓角。
- 整個選單不捲動，只有指定的內容區可以捲（背包格子、詳情、角色欄），都加了 `overscroll-behavior: contain`。
- 手機直拿時，選單開著不會顯示「請轉橫向」；關掉選單才會出現。
- 選單開著時會隱藏遊戲 HUD，任務提示不會和關閉鈕重疊。

## 觸控

- 可以點的東西至少 44×44 CSS px，`--tap` 變數統一管理。
- 不靠 hover。按下時只縮小一點，用 `transform`，成本低。
- 下拉選單字級 16px，iPhone 點了不會放大頁面。
- 雙擊放大：沿用既有設定（viewport 的 `user-scalable=no`，加上 `touch-action: manipulation`）。
- 選單背景擋住所有點擊，不會點到後面的遊戲。
- 關閉鈕固定在標頭右上角，永遠看得到。
- 觸控裝置不顯示 P、I、K、Esc 等鍵盤提示。
- 手機不用模糊濾鏡（`backdrop-filter`）。

## 稀有度

灰（普通）→ 綠（優良）→ 藍（稀有）→ 紫（史詩）→ 金（傳說）。顏色定義在 `data/items.ts` 的 `QUALITIES`，CSS 用 `--q0`～`--q4` 變數，套用時加上 `.q0`～`.q4` class。

## 背包功能

- **格子**：正方形，每列格數依可用寬度自動調整（`auto-fill`）。
- **格子上的標示**：
  - 圖示：程式畫的 SVG，依部位和職業區分。
  - 左下角：等級。
  - 右上角：誰穿著（職業頭像）。
  - 左上角：NEW，表示新拿到。
  - 右下角：▲，表示比目前角色身上的更好。
- **分類**：全部、武器、防具、飾品、消耗品（藥水）。
- **篩選與排序**：
  - 職業篩選：全部職業，或指定某職業可用的裝備。
  - 排序：依品質、戰力、等級、最新取得。
- **詳情**：
  - 前後比較分兩段：裝備本身的屬性（目前 → 新的，以及差值），和換上後角色能力值的變化。
  - 不能用的武器會提供「裝備給（能用的隊友）」。
- **一鍵最佳**：只換這個角色，不拿別人身上的裝備。
- **全隊最佳**：主角優先，依序分配。武器各職業專用，防具與飾品全隊共用。
- **通知**：分頁上會顯示新裝備數量和未分配的技能點數，頭像上也會顯示技能點數。

## 自動測試

```
node tools/qa/ui-qa.mjs bag bag
```

- **解析度**：手機橫拿 844×390、667×375，手機直拿 390×844，平板 1024×768，電腦 1440×900、1280×720。
- **檢查項目**：
  - 內容沒有超出視窗、按鈕沒有重疊、觸控區 ≥ 44px、文字沒有被截斷。
  - 格子區可以捲動（手機用觸控拖曳測），而且標頭不會跟著動。
  - 點格子會開詳情（電腦是第三欄），詳情有前後比較。
  - 在詳情面板按裝備會換上並關閉面板。
  - 分類篩選正確、全隊最佳有效。
  - 關閉鈕在畫面內而且點得到、選單擋住背景遊戲、觸控裝置不顯示鍵盤提示、沒有主控台錯誤。
- **截圖**：存在 `docs/ui-qa/bag/`。
- **限制**：
  - 安全區（瀏海）在無頭瀏覽器裡模擬不出來，要用實機確認。
  - 合成捲動手勢在無頭模式沒有作用，所以測試改成逐格送觸控事件。
