# 賣東西

## 入口
- 武器店、雜貨店、野外商人的對話裡有「賣掉不要的裝備」（背包沒有可賣的東西時反灰）。
- 選單「背包」左欄最下面的「賣東西」按鈕（隨時可開）。
- 畫面開著時遊戲暫停；Esc 或「完成」關閉並存檔。

## 標記（只看名單：出戰＋休息的隊員）
| 標記 | 意思 |
|---|---|
| 留著（綠） | 有隊員換上它會變強，而且是那個人同部位最好的備品 |
| 可賣（紅、格子發亮） | 每個能用的人都有更好的，或比身上的差 |
| 待用（灰） | 名單上沒有人能用（例如還沒入隊職業的武器），不建議賣 |
| 低（橘） | 等級比隊伍最高等級低 4 級以上（`LOW_LEVEL_GAP`） |

裝備中的東西不會列出來，也不能賣。

## 操作
- 點格子勾選／取消，下方顯示該件的屬性、售價與理由。
- 標記鈕（只動稀有以下，史詩、傳說要手動點）：**沒用的**＝可賣；**低等級**＝低且不是「留著／待用」；**普通品質**。
- **一鍵賣出沒用的**：直接賣掉「沒用的」那一組；**賣出已勾選**：賣勾選的。兩個都要按兩次（第二次是「再按一次確認」，3 秒沒按就取消）。勾到「留著」或史詩以上時，確認鈕會提醒。
- 賣價沿用背包賣出的算法：戰力分數 × 0.4（最少 1）。
