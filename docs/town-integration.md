# 星光鎮（Meshy 城鎮）整合

接在地圖第二階段 `b017c93` 之後。

素材：`public/models/starwish-town-meshy-20261123-v001/`。版本控制只收遊戲用到的 5 個檔：`town-environment.web.glb`、`town-gate.web.glb`、`navigation.json`、`town-config.json`、`npc-placement.json`。原始 GLB、8 個單獨主體與交付說明（`CLAUDE_HANDOFF.md`）只留在本機。

## 玩家看到的

- **入口**：南方街道盡頭原本封起來的關卡，換成 Meshy 城門。走進門洞下的發光圓圈就會進城。
- **城內**：整座城鎮是一個模型，包含 4 間建築、噴泉、樹、城牆、路燈、長椅和花壇。外圍補了一圈草地，遠景沿用主線世界的山脈與天空。
- **NPC**：4 位，沿用既有的 `guide-npc.glb` 和 `merchant-npc.glb`，各兩份，位置照 `npc-placement.json`。
- **門口**：4 間建築的門口各有一圈淡淡發光的門墊。建築沒有室內，在門口互動。
- **出城**：走進城門下的圓圈就回到城門外，面向村子。
- **城門淡出**：城門擋在鏡頭和主角之間時（剛進城、剛出城），城門會淡出成半透明。

### 城內功能

| 地點 | 目前功能 | 狀態 |
|---|---|---|
| 雜貨店（門口、雜貨商人） | 買生命藥水，和村子的商人相同 | 可用 |
| 旅館（門口） | 付 10 金幣，全隊回滿生命與魔力 | 可用 |
| 武器店（門口、武器商人） | 對話說明「商品還在路上」 | **尚未實作**：武器包還沒接上，不能買武器 |
| 冒險者公會（門口、引導員） | 顯示目前的任務 | 部分可用：委託板還沒做 |
| 冒險者公會（接待員） | 對話說明「轉職還在準備中」 | **尚未實作**：沒有轉職條件與流程 |

## 運作方式

| 項目 | 做法 | 檔案 |
|---|---|---|
| 地圖狀態 | `mapState.id`：`overworld` 或 `starlight-town-meshy`。每幀讀的系統看這個，React 看 store 的 `mapId` | `world/maps.ts`、`game/store.ts` |
| 切換 | `enterMap()`：清掉舊路徑、把隊伍排到新位置、換地圖、存檔 | `game/travel.ts` |
| 入口與冷卻 | 切換後要先走出入口圓圈才會重新啟用，而且有 1.5 秒冷卻 | `travel.ts`（`updatePortals`） |
| 強敵擋門 | 被事件怪、精英或首領追的時候不能進城。一般野怪不擋：城門旁就有史萊姆營地 | `travel.ts` |
| 野外的怪物 | 進城時收起來（連同掉落物），投射物與範圍效果清掉；出城時放回去，死掉的怪物補上在城裡經過的重生時間，追擊中的放棄目標回家 | `combat/state.ts`（`stashWorld`、`restoreWorld`） |
| 場景 | 同一時間只掛一張地圖。離開的那張會卸下，並釋放自己建立的網格、材質與貼圖 | `scene/GameScene.tsx`、`scene/Town.tsx` |
| 載入 | 城鎮模型載完之前，主角不出現、不能動，畫面顯示「前往星光鎮…」 | `Town.tsx`、`Player.tsx`、`ui/Overlays.tsx` |
| 載入失敗 | 退回城門外，顯示「星光鎮載入失敗，已回到城門外」，進度不受影響；下次進城會重新下載 | `Town.tsx`、`travel.ts`（`townLoadFailed`） |
| 碰撞 | 城內用 `navigation.json` 的 32 個碰撞體（4 間建築、噴泉、門樓、城牆、樹、路燈、長椅、NPC） | `data/town.ts`、`systems/collision.ts` |
| 尋路 | 城內直接用 `navigation.json` 的網格（格距 0.4 m，已含角色半徑），套進既有的 A* 與路徑拉直。只有一套尋路，主角和隊友共用 | `systems/pathfinding.ts` |
| 座標 | Blender `[x, y, z]` → Three `[x, z, -y]`；網格的列順序跟著翻轉 | `data/town.ts` |

### 外部入口座標

原本 `town-config.json` 的 `externalPortal` 是 `null`，現在已填入：

| 欄位 | 值 |
|---|---|
| 入口圓圈 | `[0.2, 0, 36.4]`，半徑 0.9 m |
| 返回位置 | `[0.2, 0, 33.2]`，面向北方（村子） |
| 城門模型 | `[0.2, 0, 36.2]`，轉 180°（正面朝北） |

如果這些欄位又變回 `null`，入口會停用，南方街道恢復成封閉關卡。不會把 `null` 當成世界原點。

### 存檔第 3 版

| 欄位 | 內容 |
|---|---|
| `mapId` | 所在地圖 |
| `returnPortal` | 在城裡存檔時，出城後回到的位置 |

- 舊存檔（第 1、2 版）沒有這兩個欄位：當作在主線世界、沒有返回位置。角色、背包、任務、寶箱與捷徑都保留。
- 城裡的存檔缺少返回位置、或位置超出城鎮範圍：分別補上城門外的預設位置和進城落點。
- 讀到城裡的存檔：先載入城鎮，再放上人物。

## 素材處理

城鎮與城門模型用 `tools/assets` 的 glTF Transform 壓縮。原檔保留在本機同一資料夾（沒有進版控）：

| 檔案 | 原檔 | 遊戲用 | 做法 |
|---|---|---|---|
| `town-environment` | 43.7 MB | `town-environment.web.glb` 6.6 MB | meshopt 網格壓縮、PNG 轉 WebP（尺寸不變，2048） |
| `town-gate` | 4.6 MB | `town-gate.web.glb` 0.6 MB | 同上 |

- 三角形數不變（300,064）。
- 樹葉的 MASK 透明材質保留。
- 沒有呼叫 Meshy，沒有額外扣點。

重新產生的指令：

```powershell
cd tools/assets
npm install
npx gltf-transform optimize ../../public/models/starwish-town-meshy-20261123-v001/town-environment.glb ../../public/models/starwish-town-meshy-20261123-v001/town-environment.web.glb --compress meshopt --texture-compress webp --texture-size 2048 --simplify false
```

8 個單獨的主體 GLB（城門以外）沒有載入，避免和整城模型重疊。

## 測試結果

測試環境是本機無頭 Edge（GPU），解析度 1280×720，手機模擬 844×390。測試腳本是 `tools/qa/town-qa.mjs`，紀錄與截圖在 `docs/map-qa/town/` 和 `docs/map-qa/town-mobile/`。

### 效能與載入

| 項目 | 結果 |
|---|---|
| 進城（從觸發到可以移動） | 約 0.4 秒（本機伺服器、有快取） |
| 出城 | 約 0.15 秒 |
| 城內讀檔（從標題按繼續） | 約 0.5 秒 |

| 反覆進出 5 次 | 幾何體 135～138、貼圖 67，沒有增加 |
