# 載入動畫與第一次進城過場

依據：2026-11-26 試玩改進建議的第七項（載入動畫）與第八項（進城過場）。兩個都是程式即時產生，沒有影片檔。

## 一、載入動畫（`ui/LoadingScreen.tsx`）

- **何時出現**：開局、讀檔、進城、回到野外——只要主角周圍的區域（或城鎮）還在載入，就蓋滿整個畫面。原本只有一顆小小的「載入中」提示。
- **畫面**（Canvas 2D 畫的，沒有圖檔）：
  - 暮色漸層天空、閃爍的星星、偶爾劃過的流星、兩層遠山剪影。
  - 「星願冒險團」標誌。
  - 小星星（有表情）沿著進度條跑，邊跑邊彈跳，後面拖著閃光。
  - 標籤：進城顯示「前往星光鎮」，其他顯示「載入地區中」。
  - 小提示輪播（每 2.8 秒換一則，共 9 則：點 NPC 自動走過去、紅圈是大招範圍、閃避無敵、任務箭頭、安全區、縮放與視角、隊友會自己打、背包比較、畫質調整）。
- **時間**：載完後至少停留 0.9 秒（太快的話只會閃一下），再用 0.38 秒淡出。
- **進度條**：沒有真實百分比可用，先快後慢逼近 92%，載完才衝到 100%。
- **不擋操作**：整層 `pointer-events: none`；載入期間主角本來就不出現、不能動。
- **手機橫拿**（高度 ≤ 460px）：標誌往上、字縮小，844×390 測過全部在畫面內，有留安全區邊距。
- **減少動態效果**（系統設定 prefers-reduced-motion）：不畫流星、小星星不彈跳、省略點點動畫。
- **效能**：2D 畫布、DPR 上限 2、星星數依畫面大小（最多 110）；載入結束就停止繪製。

## 二、第一次進城過場

- **觸發**：第一次從城門走進新版城鎮（方案 B）。城鎮載入完成後才開始；存檔記住（`unlocks` 裡的 `intro_town`），之後不再播。新遊戲會重置。讀檔時人已經在城裡，不播。
- **內容**（約 9 秒，引擎內鏡頭運鏡）：
  1. 城門外高空，斜看整座城（城牆、瞭望塔、廣場一覽）。
  2. 越過城門，沿主街往廣場低飛。
  3. 繞過噴水池與冒險者公會前。
  4. 降到主角前上方，看見主角、三位隊友和兩位新的星誓長槍衛，再平滑接回一般的跟隨鏡頭（最後 1.4 秒過渡，不會硬切）。
- **字卡**：「STARLIGHT TOWN／星光鎮」，之後一行「冒險者的第一站　·　商店、公會、旅館都在這裡」。上下黑邊滑入滑出。
- **播放時**：主角不能動、不能閃避、不能點地面；HUD 隱藏（只是看不見，狀態都還在）；背景音樂照常。
- **跳過**：Esc／Space／Enter／F、點畫面任何地方（前 0.5 秒不理）、右下「跳過 ▸」。跳過後仍有約 1.4 秒平滑回到一般鏡頭。
- **播完**：顯示原本的城鎮名稱橫幅（安全區提示）。第一次進城的橫幅等過場播完才出現。
- **只支援方案 B**：`?town=a` 與 `?town=classic` 不播（座標不同）。
- **程式**：`game/cutscene.ts`（狀態、路徑、跳過）、`scene/CameraRig.tsx`（鏡頭混合）、`ui/TownIntro.tsx`（黑邊、字卡、跳過鈕）。路徑改關鍵點就能換運鏡：`cutscene.ts` 的 `POS` / `LOOK`。

## 三、給自動測試的注意事項

自動化瀏覽器（`navigator.webdriver`）預設**不播過場、載入畫面不停留不淡出**，免得擋住既有的流程測試。測試時要驗證才打開：

```js
window.__sw.cutscene.cutscene.force = true // 過場
window.__sw.loadUi.force = true // 載入畫面用正式的停留與淡出
```

## 四、測試

`tools/qa/intro-qa.mjs`（截圖在 `docs/intro-qa/intro/`）：

- 載入畫面：開局、進城時出現、有畫布與提示、標籤正確、不擋點擊、載完後淡出；手機橫拿 844×390 放得下。
- 過場：預設不播、強制啟用後第一次進城播放；HUD 隱藏、黑邊、字卡；鏡頭沿路徑移動且起點在高處；按 W 主角不動；存檔記住；Space／點畫面／跳過鈕都能跳過；結束後 HUD 恢復、鏡頭回到主角身邊、可以移動、顯示橫幅；出城再進城不重播；取消排程不會卡住；主控台沒有錯誤。

## 五、還沒驗證

- 手機實機：載入畫面的 Canvas 與過場的幀率、安全區（瀏海）表現。
- 過場的鏡頭路徑是固定的；如果之後調整城鎮配置（建築位置、城牆），要重新看一次路徑有沒有穿過建築。
- 載入畫面的最短停留（0.9 秒）是為了不閃一下；如果覺得進城太慢，可以調 `MIN_MS`。
