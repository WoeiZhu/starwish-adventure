# 武器包與掉落物模型整合

接在星光鎮整合（`5c4c064`）之後。素材：

- 武器包：`public/models/starwish-weapons-20261123-v001/`（型錄 `weapons-catalog.json`）
- 掉落物與寶箱：`public/models/` 的 7 個 GLB（對照表 `loot-items-map-20261123.json`）

## 玩家看到的

- **武器**：四個職業手上換成武器包的模型。
  - 階級依裝備的等級：LV.1～11 第 1 階、LV.12～23 第 2 階、LV.24 以上第 3 階。
  - 武器店買的武器固定用買的那一把。
  - 還沒裝備武器時用第 1 階。
- **盾牌**：騎士的盾牌依身上防具的等級換階，規則同上。
- **弓**：攻擊時播放拉弦放箭的動作。
- **箭**：弓箭手射出的是箭矢模型。技能箭會在箭旁多一顆小光球，顏色表示技能的屬性。
- **掉落物**：金幣、藥水、裝備包（武器與防具）、小布袋（飾品）。
  - 會旋轉、上下浮動。
  - 裝備仍有品質顏色的光柱。
- **寶箱**：
  - 沒開時是木箱模型。
  - 打開時播放開箱動作，之後留在原地維持打開的樣子，不能再開。
  - 讀檔或從遠處走回來時，已開的寶箱直接是打開的樣子。
- **藥水擺設**：村子商人與城裡雜貨商人旁邊有一個木箱，上面擺紅、藍、綠三瓶藥水。只是擺設，商店照舊只賣生命藥水。

### 武器店（星光鎮）

1. 選要幫誰買：隊伍裡的每個人都可以選。
2. 選武器：該職業的 3 把武器。

| 階級 | 品質 | 需要等級 | 售價 |
|---|---|---|---|
| 第 1 階 | 優良 | — | 戰力分數 × 4 |
| 第 2 階 | 稀有 | LV.12 | 戰力分數 × 4 |
| 第 3 階 | 史詩 | LV.24 | 戰力分數 × 4 |

- 武器的等級跟著使用者的等級；攻擊力依等級與品質計算，和掉落的武器相同。
- 買下後比身上的武器好就直接換上，否則放進背包。背包滿了不能買。
- 武器記下模型 id（`Item.model`），存讀檔後外觀不變。舊存檔的武器沒有這個欄位，依等級挑模型。
- 例：弓箭手 LV.1 買第 1 階約 60 金幣；LV.12 時第 1 階約 276、第 2 階約 360 金幣。

## 運作方式

| 項目 | 做法 | 檔案 |
|---|---|---|
| 武器資料 | 讀 `weapons-catalog.json`，整理成各職業 3 階、盾牌、箭 | `data/weaponModels.ts` |
| 身上的外觀 | 依裝備算出武器模型、盾牌模型、品質顏色 | `game/gear.ts` |
| 掛到手上 | 複製人物骨架時記下手部骨頭的靜止朝向。武器另外載入後掛上，換武器不必重新複製人物 | `scene/characters/Gear.tsx`、`weapons.ts` |
| 退路 | 武器模型載入中或失敗：改用原本的程序化武器 | `Gear.tsx` |
| 弓的動作 | 每把弓一個 AnimationMixer；偵測到攻擊就播放一次拉弦放箭（形變動畫） | `Gear.tsx` |
| 箭與掉落物 | 物件池先各複製好，用顯示 / 隱藏切換。模型載入前用程序化圓錐、圓盤 | `scene/CombatLayer.tsx` |
| 寶箱 | 每個寶箱一份複製與 AnimationMixer。待機播 Idle，打開播 Open 並停在最後一格 | `scene/ChestModel.tsx`、`scene/Interactables.tsx` |
| 材質 | 沒有環境貼圖時金屬會變黑：小道具一律當作非金屬 | `scene/gltf.ts`（`prepareProp`） |

## 素材處理

`tools/assets/build-web.ps1` 把原檔壓成遊戲用的 `.web.glb`：

- 網格用 meshopt 壓縮。
- 貼圖轉 WebP，縮成 512（寶箱 1024）。
- 不合併、不攤平節點：寶箱的箱蓋和弓弦有動畫。

| 素材 | 原檔 | 遊戲用 |
|---|---|---|
| 武器包 16 個 | 約 53 MB | 約 1.9 MB |
| 掉落物與寶箱 7 個 | 約 21 MB | 約 1.0 MB |

- 三角形數不變。
- 原檔只留在本機，沒有放進版本控制。
- 沒有呼叫 Meshy，沒有額外扣點。

單獨看模型的頁面：開 dev server 後瀏覽 `http://localhost:5183/tools/qa/preview.html?f=<檔名,檔名>`。
