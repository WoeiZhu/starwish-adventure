# 第二章夥伴（暗殺者、藥師）與出戰名單

依據：2026-11-26 定案的規則（`docs/lan-multiplayer-plan.md`）與使用者給的技能設計。

## 一、兩位新夥伴

| | 索恩（暗殺者，A02 影葉雙刀） | 莉拉（藥師，A04 星藥使） |
|---|---|---|
| 定位 | 近距離爆發：高暴擊、出手快 | 遠程毒素與輔助：持續傷害、補血、加速 |
| 普攻 | 近戰，間隔 0.75 秒，暴擊率 25% | 丟藥瓶（射程 8），間隔 1.3 秒 |
| 技能 1（4 秒） | **二連擊**：雙刀連砍兩下（每下 115%） | **毒性擴散**：丟毒瓶，落點 2.4 m 內的怪中毒 6 秒（每秒 45% 攻擊力，無視防禦）。中毒的怪倒下時，毒會傳給身邊正在戰鬥的怪 |
| 技能 2（7 秒） | **旋刃**：身邊 2.6 m 一圈刀光（150%） | **治療藥水**：補血量最低的隊友 28%，播放舉藥瓶的 Heal 動作 |
| 強化（25 秒） | **影葉之心**：全隊暴擊率 +20%（8 秒） | **疾行藥劑**：全隊移動速度 +35%（8 秒） |
| 必殺技（35 秒） | **瞬閃**：躍起消失（無敵 0.6 秒），從天而降落在目標身邊，重擊 340%（周圍 2.4 m 的怪 60%）並暈眩 1.2 秒 | **毒孢子**：目標位置長出一顆紫色大蘑菇，1.2 秒後爆炸（3.4 m、300%）並讓範圍內的怪中毒 5 秒；長大期間範圍內的怪會減速，避免爆炸前走掉 |

- 你給的是一般技能、必殺、輔助各一個；職業有兩個一般技能，所以**技能 2 是我補的**：暗殺者「旋刃」、藥師「治療藥水」（模型本來就有 Heal 動作）。名字和效果都可以再改。
- 冷卻照之前定的：技能 1 是 3～5 秒、技能 2 是 7 秒、強化 25 秒、必殺 35 秒。
- 隊友 AI：
  - 暗殺者：精英／Boss 或群怪時瞬閃，開打先放影葉之心，身邊 2 隻以上用旋刃，其餘二連擊。
  - 藥師：有人低於 60% 先補血，群怪放毒孢子，目標沒中毒就丟毒，2 隻以上的戰鬥補疾行藥劑。
- 技能樹各 12 格（攻擊系／職業強化系／必殺技系），結構和其他職業相同；「範圍 +」對旋刃、毒性擴散、瞬閃、毒孢子都有效。
- 武器：2026-11-27 起改用「武器擴充包」（`public/models/starwish-weapon-expansion-20261126-v001/`）。人物本體是無手持武器的 `A02-modular`／`A04-modular`，武器掛在 `WeaponRightSocket`／`WeaponLeftSocket` 上，三階外觀真的會跟著裝備換（影葉雙刀、月刃雙刀、星痕雙刃／翠綠藥典、星露藥瓶、月光藥典）。程式在 `src/data/weaponModels.ts`、`src/scene/characters/ClipEquipment.tsx`；測試 `tools/qa/companion-weapons-qa.mjs`。壓縮人物要加 `--prune false`，否則空掛點會被刪掉。
- 兩位都**不能當主角**（標題畫面仍是四職業）。

## 二、怎麼入隊（第二章月光山谷的支線）

| | 出現時機 | 地點 | 事件 |
|---|---|---|---|
| 莉拉（藥師） | 讀完月光石碑、開始「淨化山谷」之後 | 山谷中央的蘑菇群附近（6, −51） | 被失控的孢子蘑菇圍住 → 一起打倒 3 隻 → 加入 |
| 索恩（暗殺者） | 淨化山谷完成、進入「侵蝕的源頭」之後 | 山谷西側（−17, −51） | 在追蹤狼群 → 一起打倒「侵蝕的狼群首領」（精英）＋2 隻幼狼 → 加入 |

- 打完才加入（不是一答應就加入）。任務欄會多一行「（支線）……」提示，小地圖與大地圖上是藍色的 !。
- 出戰名額滿了（已經有 3 位隊友出戰）就**先進名單休息**，畫面提示「選單『隊伍』可以換人出戰」。

## 三、出戰名單（6 選 4）

- 選單「隊伍」最上面是**出戰名單**：點一下切換出戰／休息，最多 3 位隊友出戰（加主角共 4 人）。
- **休息的隊友不上場、不拿經驗**（照你的規則，等級差距是刻意的，不做追趕）。
- 休息中的隊友仍然可以在選單裡配技能點、換裝備（頭像列會標「休息」）。
- 戰鬥中不能換人；換人後野外還沒開打的怪會依出戰人數重新調整強度。
- 存檔多存一份休息名單（`bench`）。舊存檔沒有這個欄位：全員出戰；若超過 3 位，最後加入的先休息。

## 六、還沒做

- 數值是照設計估的，沒有實際打一輪量手感（特別是中毒傷害、瞬閃 340%）。
- 兩位沒有專屬的技能特效時間軸（用通用的刀光、光環、粒子）；暗殺者普攻的傷害是出手當下就算，沒有對齊雙刀動作的兩下。
- 暗殺者、藥師沒有頭頂的表情／喊話，劇情對話只有入隊這一段。
- 手機實機的幀率（同時 4 個帶動作模型）沒驗證。
